Why NEXA exists

Campus information is everywhere. Student attention is not.

NEXA is built around a simple idea: the useful parts of college life should talk to each other. A timetable should shape reminders. An email should become a task. An expense should update a real budget.

From scattered signals to one useful next step.

NEXA collects student context across academics, communications and money. NIA reads that context, identifies what matters and returns a clear action—not another feed to manage.

College email→NIA analysis→Task + reminder→Done

Academic context

Classes, rooms, faculty, exams and attendance live in the same schedule.

Notice intelligence

University mail is condensed into the dates and decisions that matter.

Student finance

Expenses, budgets, debts and splits remain connected and mathematically exact.

One conversational layer

Ask a normal question. NIA turns live student data into an answer or an action.

What is inside

A student system, not a loose collection of features.

Every module feeds the same live student context, so actions in one area can immediately help another.

01

University communications

Gmail notices are filtered, classified and summarized into clear academic updates.

02

Timetable + conflict scan

Daily class slots, faculty and rooms are organized with deterministic overlap detection.

03

Tasks + smart reminders

Assignments are prioritized and timed around the student's actual day and quiet hours.

04

Finance + shared expenses

Budget limits, spending categories, receipt scanning, debts and bill splits stay connected.

05

Documents + search

Academic documents and student records are available through dedicated screens and global search.

06

Notifications + attendance

Alerts, attendance tracking, exam context and calendar events complete the daily loop.

NIA • Nexa Intelligent Assistance

One assistant.
Two ways to think.

Connected mode uses cloud reasoning for multimodal analysis, OCR and complex decisions. Offline mode keeps essential student actions available on-device, then queues updates for a clean sync when the network returns.

Cloud intelligenceGemini reasoning, vision, live app context and 12 structured action tools.
On-device intelligenceLocal intent parsing, timetable lookup, math support and offline action queues.

Under the surface

Mobile-first outside. Full-stack underneath.

NEXA combines an Expo mobile interface, a Fastify API and a PostgreSQL data layer. Exact calculations stay deterministic; AI is used where language, context and vision matter.

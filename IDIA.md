# GLITCHERS - Project Vision & Core Idea

## Overview

**GLITCHERS** is a lightweight, high-efficiency development workspace designed for rapid AI pair programming, experimental projects, and lean software architecture.

---

## Core Principles

1. **Minimalist Architecture**: Keep the codebase lean, readable, and free from bloated dependencies.
2. **AI-First Pair Programming**: Integrated with Google Antigravity and custom agent rules (`AGENTS.md`, `Ponytail`).
3. **High Signal-to-Noise Ratio**: Focus on clean code, automated checks, and standard platform capabilities.

---

## Tech Stack & Architecture

- **Environment**: Node.js / Web Platform / Native Stdlib
- **AI Tooling**: Google Antigravity, Ponytail Plugin
- **Configuration**: `.agents/` rules, skills, and MCP integration
